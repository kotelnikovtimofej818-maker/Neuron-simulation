# 3D Neuron Simulation

Экспериментальная нейросетевая симуляция на C#, в которой нейроны располагаются в трёхмерном пространстве и формируют связи в зависимости от расстояния между ними.

Проект исследует альтернативный подход к построению нейронной сети: вместо полностью заданной матрицы связей используется пространственная организация нейронов, при которой топология сети формируется на основе положения отдельных нейронов в 3D-пространстве.

Помимо основной нейронной сети, проект содержит отдельную дофаминовую сеть, которая используется для формирования обучающего/подкрепляющего сигнала и реализации reinforcement learning-подобного механизма.

---

## Основная идея

В классической нейронной сети структура обычно задаётся заранее:

```text
Input → Hidden → Hidden → Output
```

В данном проекте нейроны дополнительно имеют координаты:

```text
(x, y, z)
```

и соединяются друг с другом в зависимости от расстояния.

Таким образом, положение нейрона становится частью структуры сети.

Основной параметр пространственного соединения:

```csharp
maxDistance = 16f;
```

Если расстояние между двумя нейронами находится в допустимом диапазоне, между ними может быть создано соединение.

# Архитектура

Проект состоит из двух взаимодействующих систем.

## 1. Основная нейронная сеть

Текущая конфигурация:

```text
2 Input
   ↓
3 Hidden
   ↓
3 Hidden
   ↓
3 Hidden
   ↓
1 Output
```

То есть:

* `2` входных нейрона;
* `3` скрытых слоя;
* по `3` нейрона в каждом скрытом слое;
* `1` выходной нейрон.

Конфигурация задаётся в конце файла:

```csharp
enuIN = 2
enuHID = {3, 3, 3}
enuOUT = 1
```

---

## 2. Дофаминовая нейронная сеть

Отдельная сеть используется для формирования сигнала подкрепления.

Текущая конфигурация:

```text
1 Dopamine Input
       ↓
3 Hidden
       ↓
2 Hidden
       ↓
3 Hidden
       ↓
1 Dopamine Output
```

Конфигурация:

```csharp
enuDoIN = 1
enuDoHID = {3, 2, 3}
enuDoOUT = 1
```

Эта часть проекта позволяет экспериментировать с разделением основной сети и сети, генерирующей сигнал подкрепления.

---

# 3D-пространство

Каждый нейрон имеет координаты `x`, `y` и `z`.

Основное пространство задаётся размерами:

```text
X = 16
Y = 16
Z = 16
```

и параметром:

```text
maxDistance = 16
```

Положение нейронов генерируется случайным образом.

Это означает, что при каждом создании сети её физическая структура может отличаться от предыдущей.

---

# Типы нейронов

В проекте реализовано несколько типов нейронов.

## Input Neuron

Входной нейрон содержит:

* координаты в 3D-пространстве;
* входное значение.

## Hidden Neuron

Скрытый нейрон содержит:

* координаты;
* собственный ID;
* веса входных соединений;
* веса соединений с другими скрытыми нейронами;
* ID связанных нейронов;
* текущее значение;
* `delta` для обратного распространения ошибки.

## Output Neuron

Выходной нейрон содержит:

* координаты;
* связи с входными нейронами;
* связи со скрытыми нейронами;
* связи с дофаминовой системой;
* веса;
* значение;
* `delta`.

Кроме основной сети, существуют отдельные классы:

```text
dopaminInputNeuron
dopaminHiddenNeuron
dopaminOutputNeuron
```

для дофаминовой сети.

---

# Формирование связей

Основная функция построения топологии:

```csharp
seekConection(...)
```

Она определяет, какие нейроны должны быть соединены.

Для этого вычисляется расстояние между нейронами в трёхмерном пространстве.

Условно:

```text
distance(A, B) <= maxDistance
        ↓
    connection
```

Для создаваемых соединений используются случайные веса в диапазоне:

```text
[-1, 1]
```

---

# Пространственная топология

Главная особенность проекта заключается в том, что структура сети не задаётся исключительно индексами слоёв.

Нейроны имеют физическое положение:

```text
       z
       ↑
       |
       |     ● neuron
       |   /
       | /
       +----------→ x
      /
     /
    y
```

Близость нейронов влияет на возможность формирования соединения.

Это позволяет рассматривать сеть как своеобразную трёхмерную нейронную систему, в которой геометрия пространства влияет на коммуникацию между нейронами.

---

# Генерация сети

Для создания нейронов используются отдельные функции.

### Входные нейроны

```csharp
genericInputs(...)
```

Создаёт входные нейроны и случайным образом размещает их в 3D-пространстве.

### Скрытые слои

```csharp
genericHiddden(...)
```

Создаёт скрытые слои.

Нейроны последующих слоёв размещаются с учётом положения нейронов предыдущего слоя.

### Выходные нейроны

```csharp
genericOutput(...)
```

Создаёт выходные нейроны и размещает их относительно существующей структуры сети.

Аналогичные функции существуют для дофаминовой сети:

```csharp
genericDopaminInputs(...)
genericDopaminHidden(...)
genericDopaminOutput(...)
```

---

# Forward Propagation

Основной прямой проход выполняется функцией:

```csharp
forwardNetwork(...)
```

Процесс можно представить так:

```text
Input
  ↓
Hidden Layer 1
  ↓
Hidden Layer 2
  ↓
Hidden Layer 3
  ↓
Output
```

Сначала значения записываются во входные нейроны.

Затем рассчитываются значения скрытых нейронов.

Для скрытых нейронов используется sigmoid-функция:

```csharp
Sigmoid(x)
```

После этого рассчитывается выход сети.

---

# Sigmoid

Используемая функция активации:

```text
              1
Sigmoid(x) = ─────────
             1 + e⁻ˣ
```

В коде реализована стандартная логистическая sigmoid-функция.

Её производная используется при обучении сети.

---

# Обучение основной сети

Функция:

```csharp
deebLearn(...)
```

реализует обучение основной сети методом, основанным на обратном распространении ошибки.

Общий процесс:

```text
Input
  ↓
Forward Pass
  ↓
Prediction
  ↓
Error
  ↓
Output Delta
  ↓
Hidden Deltas
  ↓
Weight Update
```

Сначала вычисляется предсказание:

```text
pred = forwardNetwork(...)
```

Затем оно сравнивается с целевым значением.

Полученная ошибка используется для расчёта `delta`, после чего ошибка распространяется обратно через скрытые слои.

---

# Дофаминовая сеть

Дофаминовая часть проекта реализована отдельно от основной сети.

Для неё существует собственный forward pass:

```csharp
dopaminForwardNetwork(...)
```

и собственная процедура обучения:

```csharp
dopaminDeepLearn(...)
```

Идея заключается в том, чтобы использовать отдельную сеть для формирования сигнала, который может влиять на обучение основной нейронной сети.

---

# Reinforcement Learning

Для обучения с подкреплением используется:

```csharp
dopaminRL(...)
```

В этой функции основная сеть получает предсказание, а дофаминовая система формирует сигнал подкрепления.

Упрощённая схема:

```text
              ┌──────────────┐
Input ───────►│ Main Network │──────► Action / Output
              └──────┬───────┘
                     │
                     ▼
                Environment
                     │
                     ▼
                  Reward
                     │
                     ▼
            Dopamine Network
                     │
                     ▼
              Reinforcement
                     │
                     ▼
              Main Network
```

В коде дофаминовый сигнал используется для вычисления `delta` выходного слоя, после чего ошибка распространяется назад через скрытые слои основной сети.

---

# Actor / Critic-подобная модель

Архитектуру можно рассматривать как экспериментальную модель, похожую по идее на Actor/Critic:

```text
             ┌─────────────┐
Input ──────►│    Actor    │────► Output
             └──────┬──────┘
                    │
                    ▼
              Environment
                    │
                  Reward
                    │
                    ▼
             ┌─────────────┐
             │   Critic /  │
             │  Dopamine   │
             └──────┬──────┘
                    │
                    ▼
              Learning Signal
```

Основная сеть отвечает за получение выхода, а отдельная сеть используется для формирования сигнала подкрепления.

При этом проект является экспериментальной реализацией, а не готовой реализацией конкретного стандартного RL-алгоритма.

---

# Очистка состояния

Функция:

```csharp
clearance()
```

сбрасывает внутренние значения нейронов и `delta`.

Это позволяет повторно использовать созданную структуру сети без сохранения предыдущих вычислительных состояний.

---

# Случайная генерация

Важная часть проекта — генеративное построение нейронной структуры.

При создании сети:

1. генерируются входные нейроны;
2. генерируются скрытые слои;
3. создаются выходные нейроны;
4. отдельно создаётся дофаминовая сеть;
5. между нейронами вычисляются потенциальные связи;
6. связям назначаются веса.

За счёт случайного размещения две генерации сети могут иметь различную пространственную структуру.

---

# Жизненный цикл сети

Общий алгоритм:

```text
Generate Input Neurons
        ↓
Generate Hidden Layers
        ↓
Generate Output Neurons
        ↓
Generate Dopamine Network
        ↓
Create Spatial Connections
        ↓
Assign Random Weights
        ↓
Forward Propagation
        ↓
Learning / Reinforcement Learning
```

В текущей версии `Main()` выполняет генерацию сетей и построение соединений.

Цикл запускается 100 раз:

```text
Generate Network
      ↓
Create Connections
      ↓
Repeat ×100
```

При этом `Main()` в текущем виде не запускает непосредственно `forwardNetwork`, `deebLearn`, `dopaminDeepLearn` или `dopaminRL`.

# Известные технические моменты

Код является экспериментальным, поэтому перед использованием проекта как стабильной библиотеки потребуется дополнительная проверка.

В частности, в `dopaminForwardNetwork(...)` присутствуют обращения к `outputNeurons`, хотя функция не получает эту коллекцию как параметр. Также в нескольких местах индексация массивов весов выглядит подозрительно и требует проверки.

Кроме того, в `deebLearn(...)` стоит отдельно проверить масштабирование обновления весов скрытых слоёв относительно коэффициента обучения `alpha`.

Поэтому данный репозиторий лучше рассматривать как **research / experimental project**, а не как production-ready neural network framework.

# Возможное развитие

В дальнейшем проект можно расширить следующими направлениями:

### Визуализация 3D-сети

Показывать:

```text
Neuron
  ●
  │
  │ connection
  │
  ●
Neuron
```

непосредственно в 3D-пространстве.

### Динамическое создание связей

Разрешить нейронам создавать или удалять связи во время работы сети.

### Динамические веса

Изменять веса не только посредством backpropagation, но и непосредственно под влиянием дофаминового сигнала.

### Более полноценное RL

Добавить:

* environment;
* actions;
* rewards;
* episodes;
* policy;
* value estimation;
* reward history.

### Сохранение состояния

Добавить возможность сохранять:

```text
Neuron positions
Connections
Weights
Network configuration
```

и загружать ранее созданную сеть.
